Конструкция This is ...

This is a dog.

This is … - конструкция, которая переводится как "Это (есть) …" . Эта конструкция используется, например, для того, чтобы представить какой-нибудь предмет.

This is a table. - Это стол.
This is a chair. - Это стул.



Артикли. Неопределенный артикль

This is a banana.
This is an apple.

В английском языке есть особенные слова, которые называются "артикли". Артикли - это специальные слова, которые ставятся перед существительными. На русский язык они не переводятся, но люди, говорящие по-английски, так привыкли их использовать, что без них во многих случаях английские фразы звучат неправильно.

На этом уроке мы познакомимся с неопределенным артиклем A. Этот артикль обозначает “один, какой-то” и обычно употребляется тогда, когда мы мало знаем о каком-нибудь предмете, например, если мы называем предмет впервые в какой-нибудь ситуации.

Сегодня мы познакомились с конструкцией This is, и с ней нужно употреблять артикль a, когда речь идет о каком-то одном предмете.

This is a bag. - Это сумка.
This is a lamp. - Это лампа.

Запомни! Перед словами, начинающимися с согласной, неопределенный артикль имеет форму a, а перед словами, начинающимися с гласной, - форму an.

This is a cat. - Это кошка.
This is an elephant. - Это слон.
