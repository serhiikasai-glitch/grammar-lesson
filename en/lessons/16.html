Pattern there is/there are

Pattern there is / there are can say that a person or thing exists, or does not exist, in a place. Its meaning is similar to there exists, is.

A sentence with there is/there are follow this pattern:

There is + one thing + place
or
There are + several things + place

In other languages, a sentence with this meaning may start with the location and use verbs such as to be located, to lie, to stand, to hang and so on

There is a book on the table.
On the table there is a book.
There are pencils on the book.
There are

Notice that after there is/there are a new singular countable noun normally takes a/an; a plural does not. A specific location usually takes the.

Remember that sentences using there is/there are can answer questions such as What is there...? What is there in a place?. Compare:

What is there on the table? – There is a book on the table.
What is there on the table? — There is a book on the table.

Where is the book? – The book is on the table.
Where is the book? — The book is on the table.

To say that something is not there, after the pattern there is/there are put the word no.

There is no TV set in this room.
There is no TV set in this room.
There are no chairs in this room.
In this room not any chairs.
